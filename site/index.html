ClawGuard

Revolutionary security scanner that thinks like an attacker. LLM-powered semantic analysis catches what pattern matching misses.

⭐ Star on GitHub 📦 View on npm
npm install -g @dribgib/clawguard

⟩ The Problem

AI agents can install and run skills — code that extends their capabilities. But this creates a massive attack surface.

🔑

Credential Theft

Skills that look helpful but steal your SSH keys, AWS credentials, and API tokens.

💬

Prompt Injection

Hidden instructions that hijack the agent's behavior — "ignore previous rules" attacks.

🔗

Attack Chains

Multiple "innocent" skills that combine to form credential exfiltration pipelines.

🎭

Social Engineering

Skills that manipulate the agent to bypass its own safety rules.

Traditional security tools don't catch these attacks because they scan for code patterns, not intent.

⟩ 5 Layers of Protection

Defense in depth. Each layer catches what the others miss.

1

Static Analysis

⚡ Instant • Always runs

36 patterns detecting credential theft, code injection, persistence, and obfuscation. Catches obvious attacks in milliseconds.

2

Semantic Analysis

🧠 3-15 seconds • LLM-powered

Uses AI to understand skill intent. Catches prompt injection, capability-purpose mismatch, social engineering, and delayed triggers.

3

Attack Chain Detection

🔗 Multi-skill analysis

Scans your entire skill library for dangerous combinations. Two "innocent" skills that together form an exfiltration pipeline? We catch that.

4

Behavioral Sandbox

🍯 5-30 seconds • Docker

Runs skills in isolation with honeypot credential files. If the skill touches fake credentials → DEFINITIVE proof of malicious intent.

5

Known-Bad Database

🚫 Instant lookup

Checks skill hash against community-reported malware. Known threats are blocked before analysis even runs.

⟩ Features

Built for the agent security threat model.

🔍

Scan Local or Remote

Scan skills from disk or directly from GitHub URLs. Sparse checkout means fast downloads.

🤖

Multi-Provider AI

Works with Anthropic, OpenAI, or local Ollama models. Your choice.

🚦

CI/CD Gate

Pre-install security gate with JSON output. Block dangerous skills before they're installed.

📊

Intent Graphs

Visualize data flow through skills. ASCII or Mermaid diagram output.

🖥️

Interactive TUI

Full-screen terminal interface for security scanning with style.

⚡

Fast Mode

Skip semantic analysis for instant scans. Static-only takes ~30ms.

⟩ Quick Start

Up and running in 60 seconds.

# Install globally
$ npm install -g @dribgib/clawguard
# Configure AI provider (optional)
$ clawguard config
# Scan a skill
$ clawguard scan ./my-skill
# Or scan from GitHub
$ clawguard scan https://github.com/user/skill
# Learn how we protect you
$ clawguard about
