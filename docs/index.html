5 Layers of Protection

Each layer catches what the previous one missed. Together, they provide comprehensive coverage.

1

🔍 Static Analysis

Pattern matching across shell scripts, JavaScript/TypeScript, and YAML. Detects credential theft, code injection, persistence mechanisms, and obfuscation techniques.

base64 decode curl | bash crontab env vars ssh keys
2

🧠 Semantic Analysis

LLM-powered intent detection. Understands what code is trying to do, not just what patterns it matches. Catches novel attacks that static patterns miss.

Anthropic Claude OpenAI GPT-4 Ollama (local)
3

🔗 Attack Chain Detection

Analyzes multiple skills together to detect coordinated attacks. Skill A might look safe, Skill B might look safe, but A+B = data exfiltration.

data flow privilege escalation split execution
4

🪤 Behavioral Sandbox

Docker-isolated execution with honeypot traps. Plants fake credentials, AWS keys, and SSH keys. If the skill touches them, we have proof of malicious intent.

Docker container strace monitoring network capture honeypot files
5

🚫 Known-Bad Database

Community threat intelligence. Skills flagged as malicious are instantly blocked. No scan needed—if it's in the database, it's blocked.

SHA-256 hashing threat intel API community reports
Capabilities

Built for Real Threats

Every feature exists because we've seen these attacks in the wild.

⚡

Fast by Default

Static analysis runs in milliseconds. Use --fast for quick checks, or let semantic analysis run when you need deep inspection.

🎯

Pre-Install Gate

clawguard gate ./skill returns JSON with allowed: true/false. Exit code 0 = safe, 2 = blocked. Perfect for CI/CD.

🌐

URL Support

Scan directly from GitHub repos, tar.gz, or zip archives. Sparse checkout for subdirectories. No need to clone first.

📊

Interactive TUI

Beautiful terminal interface with real-time scanning, threat visualization, and configuration wizard.

🔒

Privacy First

Use Ollama for 100% local scanning. Your code never leaves your machine. Or use cloud APIs when you need the best models.

📝

Multiple Outputs

JSON for automation, Markdown for reports, or human-readable terminal output. Integrates with any workflow.
